# Analyse de données – Bike Sharing

Projet d'analyse exploratoire des données de location de vélos avec **Python, Pandas, NumPy et Matplotlib**.

### Objectif

Analyser les habitudes de location et étudier l'influence de l'heure, de la météo, de la température et des jours travaillés sur la demande.

### Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

### Dataset

Bike Sharing Dataset :

[https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset](https://www.kaggle.com/datasets/sriramm2010/uci-bike-sharing-data)

Le fichier utilisé dans l'analyse est `hour.csv`.

### Contenu

- `bike_analysis.ipynb` → analyse complète
- `requirements.txt` → bibliothèques utilisées
